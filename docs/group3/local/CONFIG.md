# Local Speech Configuration

## Backend `.env`

Start from `.env.example`. No STT/TTS provider API key is used.

| Variable | Default | Purpose |
|---|---|---|
| `STT_PROVIDER` | `local` | `local`; `mock` only under Spring `dev`/`test` profile |
| `TTS_PROVIDER` | `local` | `local`; `mock` only under `dev`/`test` |
| `STT_MODE` | `streaming_only` | `streaming_only`, `final_only`, `dual` |
| `LOCAL_INFERENCE_URL` | `http://127.0.0.1:8000` | Backend-local inference address; do not expose it to FE |
| `LOCAL_INFERENCE_TOKEN` | generated by `scripts/setup-inference.ps1` | Random internal service token; required for inference requests |
| `LOCAL_REQUEST_TIMEOUT_S` | `180` | Final transcription request timeout |
| `STT_FINAL_TIMEOUT_S` | `30` | Turn finalization wait |
| `STT_MAX_SESSION_DURATION_SECONDS` | `60` | DEVICE_CHECK WebSocket wall/audio limit |
| `STT_MAX_FRAME_BYTES` | `24000` | FE PCM16 frame limit |
| `SESSION_STT_MAX_SECONDS` | `180` | Local exam ring buffer cap |
| `DEVICE_CHECK_STT_SESSIONS_PER_MINUTE` | `5` | Per-student device-check rate cap |
| `AUDIO_RETENTION_DAYS` | `30` | Scheduled cleanup for configured EXAM audio storage |
| `STT_ALLOWED_ORIGINS` | `http://localhost:5173` | Exact browser origin allowlist |
| `LOCAL_CONNECT_TIMEOUT_MS` | `2000` | Local service connect timeout |
| `STT_BREAKER_FAILURE_THRESHOLD` | `5` | Local inference breaker opening threshold |
| `STT_BREAKER_OPEN_SECONDS` | `15` | Local inference breaker cooloff |
| `MAX_REPEAT_PER_TURN` | `2` | Max low-confidence/uncertain request repeats |
| `LOCAL_STT_PROMPT_MAX_TOKENS` | `160` | Initial prompt token budget |

## Inference service

| Variable | Default | Purpose |
|---|---|---|
| `BIND_HOST` / `PORT` | `127.0.0.1` / `8000` | Loopback service bind; remote bind fails unless explicitly allowed |
| `MODELS_DIR` / `HF_HOME` | `/models` / `/models/hf-cache` | Local weight/cache storage |
| `LOCAL_STT_MODEL` | `/models/stt/large-v3-turbo-ct2` | Pinned, converted Whisper model path |
| `LOCAL_STT_FALLBACK_MODEL` | `/models/stt/base` | Explicit base/int8 fallback |
| `LOCAL_STT_DEVICE` | profile-specific | `cuda`, `cpu`, or `auto` |
| `LOCAL_STT_COMPUTE_TYPE` | `int8_float16` | CTranslate2 compute type |
| `LOCAL_STT_CPU_THREADS` | `8` | CPU fallback threads |
| `LOCAL_STT_PARTIAL_INTERVAL_MS` | `1000` | Windowed partial cadence |
| `LOCAL_STT_COMMIT_SILENCE_MS` | `700` | VAD segment endpoint silence |
| `LOCAL_STT_MAX_SEGMENT_S` | `28` | Maximum speech segment duration |
| `LOCAL_STT_MAX_AUDIO_S` | `180` | Maximum inference turn duration |
| `LOCAL_STT_MAX_CONCURRENT` | `1` | Model concurrency semaphore |
| `LOCAL_STT_PARTIAL_BEAM_SIZE` / `LOCAL_STT_FINAL_BEAM_SIZE` | `1` / `5` | Decode quality/latency settings |
| `LOCAL_STT_PARTIAL_AGREEMENT_ROUNDS` | `2` | Stable prefix agreement rounds |
| `LOCAL_STT_QUEUE_WAIT_MS` | `250` | Queue admission timeout |
| `LOCAL_STT_PROMPT_MAX_TOKENS` | `160` | Initial prompt token budget |
| `LOCAL_STT_CONFIDENCE_THRESHOLD` | `0.35` | `needs_human_review` threshold |
| `LOCAL_STT_NO_SPEECH_THRESHOLD` | `0.6` | Silence/hallucination rejection threshold |
| `LOCAL_STT_LOGPROB_THRESHOLD` / `LOCAL_STT_COMPRESSION_RATIO_THRESHOLD` | `-1.0` / `2.4` | Suspicious segment guards |
| `LOCAL_STT_REPEAT_LIMIT` | `4` | Repetition-loop phrase filter threshold |
| `LOCAL_STT_HALLUCINATION_PHRASES` | sample English/Vietnamese phrases | Comma-separated phrase deny list; tune with evaluation corpus |
| `LOCAL_TTS_ENGINE` | `piper` | Local engine selector |
| `LOCAL_TTS_VOICE_VI` / `LOCAL_TTS_VOICE_EN` | vais1000 / lessac | Installed `.onnx` voice paths |
| `LOCAL_TTS_DEVICE` / `LOCAL_TTS_USE_CUDA` | `cpu` / `false` | Piper execution device; GPU requires `onnxruntime-gpu` and is opt-in |
| `LOCAL_TTS_SPEED` | `1.0` | Fixed exam voice rate |
| `LOCAL_TTS_NORMALIZE` | `true` | Single service-side normalization switch |
| `LOCAL_TTS_PRONUNCIATION_LEXICON` | `/srv/inference/data/pronunciation_lexicon.json` | Course acronym pronunciation map |
| `LOCAL_TTS_CACHE_MAX_ENTRIES` / `LOCAL_TTS_CACHE_DIR` | `256` / `/models/tts-cache` | In-memory cache bound; cache artifacts/setting root |
| `LOCAL_TTS_MAX_TEXT_LENGTH` | `4000` | Input cap |
| `LOCAL_INFERENCE_TOKEN` | unset | Must exactly match backend value; never logged |

Changing host profile, installed model path or performance parameters invalidates the previous benchmark result. Health reports actual loaded device/model/compute type.
